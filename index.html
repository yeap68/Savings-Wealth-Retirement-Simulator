6. How investment references are used

Bank Deposit — a low-return savings/deposit reference. The planning return remains editable because actual rates vary by bank, product and tenure.
EPF — a Malaysian retirement-savings reference. Declared historical dividends are reference information rather than guaranteed future returns.
MGS / GII — Malaysian government-security reference. Yield, coupon/profit payments, market price and actual realised returns are not necessarily the same.
QQQ and CIBR — equity ETF references. Their market values and returns can fluctuate substantially. The simulator uses the editable planning return entered by the user rather than treating historical performance as a future return guarantee.
Custom Investment — add as many independently named holdings as required. Each can have its own planning return and allocation.
